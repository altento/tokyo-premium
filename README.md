# Tokyo Premium — ресторан японской кухни

PHP-сайт продолжен из существующей резервной копии. Меню, заказы и брони хранятся в SQLite.

## Запуск

Требуется PHP 8.1+ с PDO SQLite. Для локального PHP в Windows:

    $php = (Get-Command php).Source
    $ext = Join-Path (Split-Path $php) "ext"
    php -d "extension_dir=$ext" -d extension=php_sqlite3.dll -d extension=php_pdo_sqlite.dll -S 127.0.0.1:8080 -t .

Откройте http://127.0.0.1:8080. При первом запросе будет создана SQLite-база и загружено вымышленное меню учебной концепции Tokyo Premium. Для постоянного окружения задайте RESTAURANT_DB абсолютным путём к файлу базы в каталоге с правом записи. Структура находится в schema.sql, а одноразовое заполнение учебным меню и отзывами — в seed.sql.

Создание администратора из PowerShell: php -d "extension_dir=$ext" -d extension=php_sqlite3.dll -d extension=php_pdo_sqlite.dll .\setup_admin.php. Скрипт запросит email и пароль от 12 символов и сохранит пароль в виде хеша. Панель доступна по /admin.php.

## Возможности

- Меню с категориями, поиском, сортировкой по цене и названию.
- Избранное и корзина, сохраняющаяся между страницами; сумма заказа рассчитывается на сервере по БД.
- Заказ с безопасным подтверждением без списания оплаты.
- Бронирование с проверкой даты, времени и числа гостей.
- Аккаунты с хешированными паролями и историей заказов и броней.
- Отзывы с премодерацией.
- Админка: добавление, изменение и удаление блюд; доступность позиций; статусы заказов/броней; отзывы, SEO-настройки и тексты первого экрана.
- CSRF, подготовленные запросы, серверная валидация, сессии HttpOnly/SameSite.
- Адаптивный дизайн, анимации CSS с учётом prefers-reduced-motion.

## Демонстрационные данные

Tokyo Premium — вымышленная ресторанная концепция для лабораторной работы. История бренда, шеф-повар, адрес, телефон, расписание, меню, цены и опубликованные отзывы придуманы для учебной демонстрации и не относятся к действующему заведению. Все данные можно менять через админ-панель. Перед размещением проверьте права и условия использования фотографий Unsplash. Не добавляйте в репозиторий базу данных и реальные данные пользователей.

## Публичная демоверсия на GitHub Pages

Публичный адрес: https://altento.github.io/tokyo-premium/. После каждого обновления `main` GitHub Actions собирает статическую версию сайта и публикует её. На GitHub Pages PHP и SQLite не запускаются: формы заказа, бронирования и отзывов в публичной демоверсии сохраняют тестовые записи только в локальном браузере; вход, база данных и административная панель доступны при запуске PHP-версии из раздела выше.
