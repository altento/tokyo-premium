# Полная PHP-версия на домашнем Windows-компьютере

Сайт и SQLite работают дома. С ноутбука открывается адрес домашнего сервера. Компьютер дома должен оставаться включённым, без сна, с работающим сервером и интернетом. Публичная GitHub Pages остаётся отдельной статической демонстрацией.

## Запуск

В PowerShell из каталога проекта:

```powershell
.\Start-Tokyo.ps1 -CheckOnly
.\Start-Tokyo.ps1 -SetupAdmin
.\Start-Tokyo.ps1
```

Если политика Windows блокирует локальный скрипт, запустите его в отдельном процессе:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Tokyo.ps1
```

Скрипт находит PHP, загружает установленное расширение PDO SQLite при необходимости, проверяет SQLite и запускает `http://127.0.0.1:8080`. Другой порт: `-Port 8090`. Другой PHP: `-PhpPath 'C:\path\php.exe'`. Вкладку PowerShell нужно держать открытой; Ctrl+C останавливает сервер. Создание администратора выполняется только локально в терминале.

По умолчанию база находится в `%LOCALAPPDATA%\TokyoPremium\data\restaurant.sqlite`, вне публичной папки проекта. Если уже есть база, перед обеими командами задайте `$env:RESTAURANT_DB` её абсолютным путём. Скрипт не переносит и не заменяет старую базу. Для резервной копии остановите сервер и скопируйте весь каталог данных; не копируйте только SQLite-файл во время активной записи.

Сервер использует `tools/home-router.php`: доступны только явные страницы приложения и CSS/JS/медиа. База, SQL, `.env`, Git, инструкции, CLI-установщик и служебный код не выдаются по URL. Не запускайте для туннеля голый `php -S ... -t .` без этого роутера.

## Личный доступ из университета

Установите Tailscale на оба компьютера и войдите в одну сеть. Дома после запуска сайта выполните:

```powershell
tailscale serve 8080
```

Откройте показанный HTTPS-адрес на ноутбуке с работающим Tailscale. Serve ограничивает доступ участниками вашей Tailscale-сети; админке сайта всё равно нужен её собственный пароль. Преподавателю можно показать сайт с ноутбука. Установка и вход в Tailscale требуют вашей учётной записи; скрипт проекта их не выполняет.

Официальная инструкция: https://tailscale.com/docs/features/tailscale-serve

## Публичный адрес и оплата

Для публичного показа без Tailscale на ноутбуке нужен публичный туннель, например Cloudflare Tunnel со стабильным доменом. Он должен направлять запросы на `http://127.0.0.1:8080`. Сначала проверьте авторизацию администратора и используйте только учебные данные. Не публикуйте RDP, файловые папки или весь диск.

Установка туннеля: https://developers.cloudflare.com/tunnel/get-started/

FreedomPay требует стабильный публичный HTTPS-адрес для серверного callback и настроенный мерчант. Закрытый Tailscale Serve не доступен платёжному провайдеру. Переменные оплаты описаны в `freedompay-payments.md`. На публичном туннеле завершение TLS происходит перед PHP; установите `$env:TOKYO_HTTPS_ONLY='1'` перед запуском сайта, чтобы сессионные cookies отправлялись только по HTTPS. Затем открывайте именно HTTPS-адрес туннеля.

Встроенный PHP-сервер предназначен для учебного показа с небольшой нагрузкой. Для постоянного публичного обслуживания используйте PHP-хостинг либо настроенный веб-сервер, резервные копии и мониторинг. Реальные списания и отправка почты требуют настроенных внешних сервисов.
