# История заказов на мобильном кабинете — 23 ноября 2026

На телефонах карточка заказа теперь размещает сумму рядом с короткими данными заказа, а состав и повтор — в общей нижней строке. Метаданные остаются видимыми, текст состава раскрывается штатным `details`, кнопка повтора сохраняет высоту 44 px. Desktop-раскладка не менялась.

## Проверка

- `node tests/account-demo-regression.cjs` на локальном Pages-экспорте — пройдено. Сценарий проверил browser-local историю, состав, повтор, очистку, уведомления и отсутствие горизонтального переполнения.
- Playwright проверил высоту мобильной карточки при 390 px: не более 190 CSS px; проверка кнопок вкладок и остальных мобильных состояний также прошла.
- Полноразмерные seeded captures: `local/11-account-seeded-mobile.jpg` и `local/11-account-seeded-desktop.jpg`; оба просмотрены.

## Сверка с макетом №11

На мобильном данные заказа больше не растягиваются в отдельные последовательные блоки, при этом состав остаётся раскрываемым, а действие повтора удобно нажимать. Весь экран кабинета остаётся длиннее макета из-за честных пояснений о локальном хранении, истории бронирования, избранном и адресах. Полное пиксельное соответствие не заявляется.
