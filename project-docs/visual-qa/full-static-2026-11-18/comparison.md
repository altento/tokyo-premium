# Сверка 11 страниц с утверждёнными макетами — 2026-11-18

## Объём проверки

Сняты свежие полноразмерные скриншоты статической демоверсии для 11 маршрутов на ширинах 1440 и 390 CSS px. Два контакт-листа сопоставляют каждый маршрут с соответствующим PNG из `design-references/`; оба листа просмотрены. Полноразмерно дополнительно осмотрены кабинет и заполненная корзина. Это ручная визуальная оценка, не попиксельное сравнение. Данный свежий набор относится к Pages; PHP-вариант не переснимался.

Файлы: `*-static-desktop.jpg`, `*-static-mobile.jpg`, `comparison-sheet-01-06.jpg`, `comparison-sheet-07-11.jpg`. Для заполненной корзины, самовывоза, доставки и ошибок формы используйте также `../cart-progressive-checkout-2026-11-17/` — там восемь отдельных состояний.

## Следующая визуальная работа

1. Сблизить карточку блюда с макетом через фактически разные фотографии продукта и компактную информационную полосу; не выдавать повторное кадрирование за галерею.
2. Уплотнить композицию кабинета и главной на широких экранах, сохранив мобильный порядок и честное обозначение локальных примеров.
3. После CSS/контентных правок переснять затронутые маршруты и проверить на 320/390/768/1024/1440/1920 px. Широкие размеры не заменяют проверку длинных страниц и состояний.

## Ограничения доказательств

- Этот отчёт подтверждает просмотр свежих сравнительных листов и отдельных полных экранов, но не утверждает пиксельную идентичность макетам.
- Корзина здесь представлена отдельным набором seeded-состояний; свежие default captures намеренно показывают чистый первый визит.
- Наличие статических скриншотов не подтверждает PHP/SQLite поведение или опубликованный результат; эти проверки фиксируются отдельно.
