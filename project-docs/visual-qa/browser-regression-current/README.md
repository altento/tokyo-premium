# Browser regression captures

Generated by `npm run test:browser` after updating the booking selector to target the SVG copy of a table ID. The run passed for the PHP site and the local static export.

Captures include desktop and mobile full-page screenshots for the 11 route families, the gallery filter state, and a seeded account state. The regression also exercised all 20 dish detail routes, cart/checkout, navigation, favorites, catalog filters, and six viewport widths.

These are local regression results for the current branch. They do not confirm that the public GitHub Pages site has been updated.
