## Поведение и экспорт

- `npm run test:browser` прошёл: 11 маршрутов, 52 страницы блюд после серверного открытия Secret Menu, PHP checkout и booking, кабинет, корзина и статические сценарии; проверка всех шести ширин прошла.
- `npm run test:tokyo20` прошёл в PHP и Pages: 52 и 50 доступных страниц блюд соответственно, предложения, Omakase, подбор сета, бронирование, профиль и мобильные границы.
- `npm run test:review-contact-forms` прошёл для PHP и Pages; `npm run test:reviews` проверил локальный отзыв, очистку, безопасный текст и неизменный публичный рейтинг.
- `npm run test:admin-marketing-browser` и `npm run test:admin-booking-browser` прошли на временных базах: акции/коллекции, модерация отзывов, поиск бронирования, подтверждение и отмена.
- Экспорт перестал вставлять `pages-demo.js`, когда у соседнего script-тега был cache-busting query. Теперь Pages загружает локальный обработчик; браузер подтвердил, что заказ сохраняется в `localStorage` и не уходит в PHP API.
- Миграция v21 исправляет только два известных старых пути фото. Проверка на копии базы подтвердила, что вручную заданное фото блюда миграция сохраняет.

## Оставшиеся ограничения

В существующем расширенном каталоге найдены и другие блюда с общими путями изображений. В этом проходе исправлены именно два подтверждённых неверных фото; для остальных повторно используемых кадров нужна предметная сверка каждого блюда. Случайных фото и копий для новых позиций не добавлял.

Запросы Chromium к Google Fonts недоступны из этой cloud-среды; страницы проверялись с системными запасными шрифтами. Прямой запрос к публичному домену Pages также закрыт сетевой политикой этой среды, поэтому результат Actions и сам URL после отправки в GitHub проверяются отдельно.
